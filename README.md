# Football Match Outcome Prediction

## Project Description
Proyek ini dikembangkan untuk memprediksi hasil akhir pertandingan sepak bola musim 2024/2025 (Menang, Seri, Kalah) berdasarkan data historis pertandingan menggunakan pendekatan Machine Learning / Neural Network.

## Latar Belakang
Sepak bola merupakan olahraga dengan dinamika yang tinggi, di mana hasil pertandingan dipengaruhi oleh banyak faktor seperti performa tim, lokasi pertandingan, hingga statistik gol. Pemanfaatan teknologi kecerdasan buatan, khususnya Neural Network, memungkinkan kita untuk menganalisis pola dari data masa lalu guna menyajikan prediksi hasil pertandingan yang lebih terukur dan akurat.

## Rumusan Masalah
1. Bagaimana cara mengolah data historis pertandingan sepak bola agar siap digunakan dalam pemodelan AI?
2. Bagaimana arsitektur Neural Network yang optimal untuk mengklasifikasikan hasil pertandingan ke dalam 3 kelas (Menang, Seri, Kalah)?
3. Seberapa tinggi tingkat akurasi dan performa model yang dihasilkan dalam memprediksi hasil pertandingan musim 2024/2025?

## Tujuan
1. Melakukan preprocessing dan transformasi data pada dataset Football Matches 2024/2025.
2. Membangun dan melatih model Neural Network untuk klasifikasi hasil pertandingan sepak bola.
3. Mengevaluasi performa model berdasarkan metrik akurasi, presisi, recall, dan F1-score.
